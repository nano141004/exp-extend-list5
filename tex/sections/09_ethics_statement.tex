\section*{Ethics Statement}

This work evaluates retrieval reranking methods on existing BEIR benchmark datasets and does not introduce new human-subject data collection.
The main ethical considerations are inherited from the datasets and from the downstream use of retrieval systems.
Rerankers can affect which information users see first, so performance differences should be interpreted carefully across domains and should not be assumed to imply fairness, factuality, or reliability in deployment.
Any released results should cite the original datasets and model sources and respect their licenses.
